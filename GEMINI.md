# Project Instructions: LivingPDFs.com

Specific instructions for the LivingPDFs.com project.

## Project Goal
LivingPDFs is an AI-powered application, likely integrated with Google AI Studio, that provides interactive PDF experiences. It includes a payment system for different subscription tiers.

## Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express (server.ts)
- **Payments:** Stripe API (version 2025-02-24.acacia)
- **AI Integration:** Gemini API / Google AI Studio

## Conventions
- **Server:** Express server runs in conjunction with Vite development server.
- **Environment:** Requires `GEMINI_API_KEY` and `STRIPE_SECRET_KEY` in environment variables.
- **Styling:** Tailwind CSS is used for frontend components.
